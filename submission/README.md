# 세 상품의 실제 검사 기록과 평가 결과

최종 영상은 소리 없이 **1분 56.68초** 동안 재생됩니다. 이 저장소에는 영상 파일 대신 [장면 해설과 실제 화면](demo/DEMO-EXPLAINED.md), [한국어 자막](demo/film-ko.vtt)을 실었습니다.

팀은 영상을 찍을 때 사용한 판(0430)의 실행 기록을 실었습니다. 제출한 판(0505)은 GPU 없이 그 기록을 재생합니다. [달라진 다섯 파일과 아직 확인하지 못한 점](../README.md), [파일별 해시](release.json), [촬영 해설](demo/DEMO-EXPLAINED.md)을 확인하세요.

1. 앱은 Nitrotest 상품 페이지의 성분표를 읽고 식약처가 지정한 원료를 표시합니다.
2. GravityOCR-KO는 Stimerex의 과거 라벨 사진에서 글을 읽습니다. 판매자 역할의 스크립트가 위치를 모른다고 답해도 앱은 이미 찾은 차단 근거를 버리지 않습니다.
3. 앱은 Rapi-Melt 앞면만 보고 문제없다고 하지 않습니다. 먼저 제조사에 보낼 문의 초안을 씁니다. 이어서 시험자가 보관한 라벨을 넣으면 같은 검사를 계속합니다.

## 실제 Zoro-1으로 검사한 세 상품

| 상품과 실행 기록 | 앱은 무엇을 했나요? | 검사에 걸린 시간 | Zoro-1 호출 |
|---|---|---:|---:|
| [1. Nitrotest](logs/scenario-01.md) | 앱이 본문에서 차단 성분을 찾아 “등록 보류 권고”를 표시했습니다. | 12.775초 | 8회 |
| [2. Stimerex Hardcore](logs/scenario-02.md) | 앱이 사진을 읽었습니다. 스크립트가 위치를 모른다고 답한 뒤에도 앱은 차단 성분을 찾아 “등록 보류 권고”를 표시했습니다. | 32.073초 | 2회 |
| [3. Blackmores Iron Rapi-Melt](logs/scenario-03.md) | 앱이 앞면에서 판단을 멈췄습니다. 다음 사진에서 성분 2개를 확인했지만 전체 상품에는 “확인 필요”가 남았습니다. | 43.468초 | 6회 |

팀은 2026-11-20 04:17–04:19 KST에 Brev의 **NVIDIA L40S**에서 촬영했습니다. 당시 서버는 `integrated-0430`(`0e4b0183`), 확장은 `e80b83ae`였습니다. 운영 환경에는 L4도 있습니다. 표의 시간은 각 검사가 시작해 끝날 때까지입니다. 편집한 영상의 길이가 아닙니다. Zoro-1 호출에는 사진 방향을 판단한 요청이 들어갑니다. 별도의 글자 읽기 요청은 세 상품에서 각각 0회, 1회, 6회였습니다. [실제 요청 기록](logs/model-calls.json), [시간순 색인](logs/run-index.json), [모델 서버 구성](infra.md)을 확인할 수 있습니다.

[검사 기록 압축 파일](logs/all-events.jsonl.gz)을 풀면 각 줄에 장면 파일명, 행 번호, 실제로 일어난 일이 나옵니다. [GPU 없이 새 폴더에서 재생한 결과](logs/replay-proof.json)는 촬영 기록이나 25개 상품 평가와 다른 시험입니다.

팀은 새 폴더에서 `./judge.sh`로 제출한 서버와 실제 Chrome 확장을 열었습니다. 촬영 당시의 답으로 세 검사를 새로 만들자 2건에서 “등록 보류 권고”, 1건에서 “확인 필요”가 나왔습니다. 앱은 Rapi-Melt의 철과 비타민 C를 다시 검사했습니다. 뒤에 받은 라벨로 점검 2개를 끝내 **4개가 남았습니다**. 영상에서는 **6개**가 남았습니다.

## 사진을 한 번만 읽은 방법과 결과가 같았나요?

개발 중 시험한 상품 25개 중 차단 원료가 있는 17개를 비교했습니다. 직구레이더는 비교 시험 때 쓴 판(0450)의 실제 API로 검사했습니다. [상품별 결과와 근거](agent-vs-no-agent-0500.md)에서 차이를 확인하세요.

| 검사 방법 | 차단 상품에서 정답 원료 ID를 찾은 수 | 대조할 근거를 확보하지 못했다고 알린 수 | 무엇을 더 확인해야 하는지 이유를 적은 수 |
|---|---:|---:|---:|
| 본문을 한 번 읽고 공식 이름과 다른 이름을 대조 | 1/17 | 16/17 | 0/17 |
| 사진을 돌리지 않고 한 번 읽어 이름을 대조 | 13/17 | 0/17 | 0/17 |
| 직구레이더 | 13/17 | 4/17 | 12/17 |

두 방법은 같은 수의 상품에서 정답 원료를 찾았지만 서로 다른 상품을 놓쳤습니다. 사진을 한 번 읽은 방법은 Stimerex에서 성분표 대신 주의문구를 읽었습니다. 직구레이더는 차단 원료를 놓친 네 상품을 모두 사람이 확인하도록 남겼습니다. 더 확인할 이유를 적은 12개 중에는 차단 근거를 일부 찾은 상품도 있습니다. 실제로 제조사에 연락한 횟수는 0건입니다. 어느 방법에서도 표시가 없다고 안전을 승인한 것은 아닙니다.

## 같은 상품 25개로 처음 만든 판과 영상을 찍은 판 비교하기

| 개발에 쓴 상품 25개에서 무엇을 셌나요? | 처음 만든 판 | 영상을 찍은 판 |
|---|---:|---:|
| 앱이 제공된 성분 자료의 검토를 끝내고 정답에 맞게 검사를 마친 상품 | 5/25 | **8/25** |
| 그중 모든 세부 항목까지 끝낸 상품 | 3/25 | 7/25 |
| 앱이 차단 상품에서 정답 원료의 공식 ID를 하나 이상 찾은 경우 | 9/17 | 13/17 |
| 앱이 차단 근거를 찾았지만 성분표 전체를 확인하지 못한 경우 | 5 | 7 |
| 앱이 사람에게 확인을 요청한 경우 | 15 | 10 |
| 차단 성분이 있는데도 앱이 확인을 끝내고 찾지 못했다고 한 경우 | 0/17 | 0/17 |
| 차단 원료가 없는데도 앱이 잘못 차단한 경우 | 0/7 | 0/7 |
| 스크립트가 답한 횟수 / 실제 사람에게 연락한 횟수 | 75 / 0 | 5 / 0 |

차단 성분이 있는 상품이 17개, 없는 상품이 7개입니다. 따로 검토할 1개는 점수에서 뺐습니다. 앱이 모든 성분을 찾았다는 뜻은 아닙니다. 개발에 쓰지 않은 상품으로 독립적으로 평가한 것도 아닙니다. 두 판은 입력을 전달하는 방법과 모델 서버, 추론 설정이 달랐습니다. 따라서 결과 차이가 모델 하나 때문이라고 볼 수 없습니다. 영상을 찍은 판은 모델 서버에 HTTP 요청을 137회 보냈고 오류는 0건이었습니다. 도구는 57회 실행했고 실패는 0건이었습니다. 각 검사에 걸린 시간을 더하면 390.179초입니다. [측정 기준과 시험 기록](logs/evaluation-25.json)을 확인하세요.

## 심사 중 직접 확인하기

- **영상과 실행 기록을 보려면** 위 장면의 설명에서 원본 JSONL의 해당 줄을 여세요. [장면에 넣은 자료와 모델이 맡은 일](demo/README.md)도 확인할 수 있습니다.
- **GPU 없이 재생하려면** [실행 안내](../START_HERE_KO.md)를 따르세요. 앱은 촬영 당시 서버가 준 답으로 판단 코드를 다시 실행합니다. 모델이 새로 추론하거나 정확도를 측정하는 것은 아닙니다.
  앱은 새 검사를 만들고 성분명을 식약처 목록과 다시 대조합니다. 원본 포장 사진 대신 파일 해시에 맞는 식별용 그림을 전달합니다. 요청과 사진 변환이 촬영 때와 같아야 저장한 답을 돌려줍니다. 다르면 요청이 실패합니다. 새 사진을 읽는 시험은 아닙니다.
- **GPU로 검사하려면** [서버 연결 안내](infra.md)를 따르세요. 운영자가 제공한 주소와 키가 필요합니다. 주소가 없거나 GPU가 꺼져 있으면 실제 검사를 할 수 없습니다.

## 팀이 직접 실행한 일과 미리 정한 일

배포하는 JSONL 파일은 촬영 당시의 요청과 응답 텍스트를 담은 사본입니다. 주소와 인증값은 가렸습니다. 외부 사진 원본 대신 파일 해시와 크기를 기록했고, 본문과 중복되는 base64 인코딩은 뺐습니다. 각 파일 첫 줄의 해시를 원래 기록과 대조할 수 있습니다.

앱은 실제로 모델 서버에 판단과 글자 읽기를 요청했고, 스크립트는 실제 확장을 조작했습니다. 판매 페이지와 라벨은 이전에 보관한 자료입니다. 스크립트는 판매자 대신 정해 둔 답을 입력하고 다음 사진을 올렸습니다. 앱은 시험용 장부에 “등록 보류 권고”를 기록했습니다. 실제 쇼핑몰은 바꾸지 않았습니다. 실제 업체가 회신하거나 쇼핑몰에서 판매를 중지한 일은 없습니다. 등록이나 통관을 승인한 일도 없습니다. 외부 사진 원본과 판매 페이지 전체 HTML은 재배포하지 않습니다. 식약처가 지정 중인 원료는 316건이고 해제된 원료까지 검색하면 318건입니다. 검색 조건이 달라서 나온 차이이지 2건을 누락한 것이 아닙니다.
