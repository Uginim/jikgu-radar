## 한 번 읽고 대조하면 무엇이 다른가

## 심사 중 직접 확인하기

- **영상과 로그:** 위 세 장면에서 각 문장을 눌러 JSONL 원본 줄로 이동한다. [장면별 입력·모델 역할](demo/README.md)을 함께 볼 수 있다.
- **GPU 없이:** [세 줄 실행법](../START_HERE_KO.md). 과거 서버 응답을 돌려주고 판단 코드를 다시 실행한다. 새 모델 추론이나 정확도 측정이 아니다.
  재생 시 새 사건을 만들고 판단 코드와 공식 목록 대조를 다시 실행한다. 원본 포장 사진 대신 지문에 대응하는 식별용 그림을 전달한다. 원래와 같은 요청·사진 변환일 때만 촬영한 판독 응답을 반환하며 일치하지 않는 요청은 실패한다. 새 사진을 인식하는 시험은 아니다.
- **GPU로:** [연결 방법](infra.md). 운영자가 제공한 주소와 키가 필요하다. 주소가 없거나 GPU가 꺼져 있으면 실검사는 할 수 없다.

## 어디까지 실제인가

공개 JSONL은 촬영 때의 요청·응답 텍스트를 보존한 사본이다. 주소·인증값을 가렸으며, 외부 사진 바이트만 지문·치수로 바꾸고 본문과 중복인 base64 인코딩을 뺐다. 각 파일 첫 행의 해시로 출처 기록과 대조할 수 있다.

판정 서버·OCR 호출과 확장 조작은 실제 실행이다. 소매점 입력은 저장한 페이지와 라벨이며 실시간 판매 페이지가 아니다. 판매자 답·자료 추가·로컬 보류 처리는 검사 스크립트가 누른 각본이다. 실제 업체 회신·판매중지·등록 승인·통관 승인은 없다. 원문 사진과 외부 사이트의 전체 HTML은 재배포하지 않는다. 원료 목록은 **지정 316건(전체 조건 318건)**이다. 서로 다른 검색 조건의 숫자이며 누락 2건을 뜻하지 않는다.
