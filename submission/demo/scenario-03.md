# 03 · 앞면만 있는 상품에 자료를 요청하고 같은 검사 이어가기

> “Blackmores Iron Rapi-Melt™” — 첫 검사에 넣은 상품명

[Blackmores 제품 페이지](https://www.blackmores.com.au/products/iron-rapi-melt)의 저장 자료에서 앞면 사진을 넣었다. 제조사에 물을 초안은 작성했지만 보내지 않았다. ‘모름’과 나중에 넣은 성분표 사진은 실제 판매자·제조사의 답이 아닌 각본이다. **0430 사건 소요 시간: 43.468초.**

| 0430 결과 화면 | 읽은 성분 | 목록에 없음 | 차단 근거가 나온 성분 | 남은 확인 |
|---|---:|---:|---:|---:|
| 앞면만 읽은 뒤 · 확인 필요 | 0 | 0 | 0 | 6 |
| 준비한 답 사진을 읽은 뒤 · 확인 필요 | 2 | 2 | 0 | 6 |

**Zoro-1이 판단한 것 / 코드가 한 것.** “앞면에서 성분표를 읽을 수 있는가?”에 모델은 `읽을 수 없음` 0.8504를 골랐다([30–34행](../logs/scenario-03.jsonl#L30-L34)). 코드는 재시도와 영역 요청 뒤 멈췄다. Zoro-1이 한·영 문의 초안을 작성했고, 준비한 사진을 **같은 사건**에 붙이자 철과 비타민 C 각각의 ‘차단 근거 없음’ 선택 확률은 0.9464·0.9700이었다([59–66행](../logs/scenario-03.jsonl#L59-L66), [94–109행](../logs/scenario-03.jsonl#L94-L109)). 순서·목록 대조·전체 확인 조건은 코드가 맡았다.

**원본에 남은 결과.** 두 항목을 추가해 다시 대조했지만 현재 상품의 전체 원료를 확인하지 못해 `확인 필요`를 유지했다([110–111행](../logs/scenario-03.jsonl#L110-L111)). [0505 제출 코드로 재생하면](../logs/replay-proof.json) 확인한 일 두 가지를 빼고 남은 점검을 4개로 표시한다. 영상과 표는 0430 당시의 6개를 보존한다.
