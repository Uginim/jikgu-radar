# 실제 GPU로 다시 검사하기

운영 환경은 Brev의 NVIDIA L4·L40S이며, 이 영상의 세 사건은 **L40S**에서 실행했다([실제 요청 장부](logs/model-calls.json)). 확장과 로컬 FastAPI 서버는 GPU가 필요 없고, 원격 추론 서버가 Zoro-1과 GravityOCR-KO를 제공한다. `/v1/systemone`은 후보 확률, `/v1/generate`는 문의 초안, `/v1/ocr`은 사진의 글자와 판독 정보를 반환한다. `record`는 새 GPU 호출을 **기록하는** 모드이지 기존 응답 재생 모드가 아니다.

1. GPU 운영자에게 해당 모델 서버 주소와 인증 필요 여부를 확인한다. 주소나 키를 저장소·화면 녹화·로그에 쓰지 않는다. 반출 자료에는 모델 가중치나 서버 생성·정지 권한이 없다.
2. 셸 환경에 `ZORO_URL`과, 인증이 필요한 경우 `ZORO_API_KEY`를 설정한 뒤 `./judge.sh live`를 실행한다. 프로그램이 확장용 로컬 API 주소를 출력한다. 실제 주소가 없으면 바로 실패하며 GPU 없는 재생으로 바꾸지 않는다.
3. `chrome://extensions`에서 `submission/runtime/extension/`을 로드한 뒤 상품 탭에서 확장 아이콘을 누른다. 패널의 서버 주소를 터미널에 나온 주소로 설정한다. 본인이 볼 권한이 있는 상품 페이지·라벨만 검사하고, 로그인이나 보안 확인을 자동으로 넘기지 않는다.

[입력별 원출처](demo/README.md)에서 직접 받은 자료를 쓸 수 있다. 페이지 개편·배합·모델 응답이 달라지면 결과도 달라질 수 있다. 현재 GPU 가동을 전제로 하지 않는다. 꺼진 GPU에는 실검사를 할 수 없고 [기록 재생](../START_HERE_KO.md)은 그대로 가능하다. 로컬 서버 종료는 `Ctrl+C`; 원격 GPU 운영과 과금은 별개다.
